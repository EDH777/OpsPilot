# 演示脚本（约 5 分钟）

> 目标：让面试官在 5 分钟内看到"自主调查 + 可观测执行 + 可复核报告"，而不是一个聊天框。

## 0. 准备（演示前完成，不要现场等）

```powershell
$env:PYTHONUTF8="1"
$py = "D:\Anaconda3\envs\chAgent\python.exe"

& $py -m opspilot.data.seed
& $py -m opspilot.mock_erp.app                        # 终端 A
& $py -m uvicorn opspilot.api.app:app --port 8100      # 终端 B
```

打开 <http://127.0.0.1:8100>，确认左下角显示"模型与数据源已就绪"。

## 1. 驾驶舱（40 秒）

- 指 KPI：产量、完成率、总电耗、**综合单位电耗**、告警。
- 指 **异常提示**："三号车间单位电耗 2.82 → 3.10，+9.8%"，点击「调查」。
- 顺带指 **数据缺失** 卡片："二号车间 27/30 天有完整记录，所以不参与异常判断"——
  说明系统不会用缺失数据硬算趋势。
- 指右上角「实时 · 时间 · 版本号」：看板是推送更新的。可以现场另开终端改一条数据，
  2~3 秒内 KPI 会自动闪一下并更新（`scripts/check_live_push.py` 可复现）。

## 2. 自主调查（90 秒）

问题已自动填入，点「开始调查」。讲解右侧轨迹：

1. `inspect_schema`：先看表结构和指标口径，不猜表名。
2. `run_sql`：对比基线期与异常期的单位电耗。
3. `run_sql`：下钻到设备级，找到 `EQ-WS03-AC01` 空转 176→500 分钟、负载率 0.70→0.45。
4. `query_alarm_api`：核对 E-207 告警的时间分布。
5. `python_analysis`：在沙箱里画图。
6. `submit_report`：结构化收尾。

讲解词：

> 注意这不是预设流程：每一步查什么，是模型看到上一步结果后才决定的。
> 工具名、参数、耗时、结果都在右边，出错会标红并自动重试。

## 3. 报告（60 秒）

报告出现后，逐块讲：

- **结论摘要**：带数字，能对回上面的查询。
- **结论与证据**：每条都标 `已验证事实 / 证据支持 / 待核实`——这是防止 LLM 把相关性说成因果的关键。
- **局限与待核实**：模型自己写"未核实维修记录、未排除设备老化"。
- 点「下载 Markdown」→ 给面试官看文件；点「查看完整 Trace」→ JSONL 事件流。

## 4. 错误恢复（60 秒，可离线）

另开终端：

```powershell
& $py -m opspilot.cli --demo recovery
```

讲解：

> 第 2 步故意请求 113 天，业务系统返回 400「跨度超过 92 天」。
> Harness 把 400 解析成结构化错误回填给模型，模型缩小到 81 天后重试成功。
> 这类"参数口径不统一"的问题，正是我做企业数字化改造时天天遇到的。

## 5. 工程底子（60 秒，可选）

```powershell
& $py -m pytest -q                                      # 47 个测试
& $py -m evals.run_eval --only t4_data_gap t5_safety    # 验收任务
```

一句话总结：

> 我把 Agent 当成一个需要"执行引擎 + 运行时保障"的系统来做：
> Loop 负责决策，Harness 负责校验、恢复、预算、状态和可观测性；
> 上层是制造企业的真实业务语义（指标口径、只读权限、数据质量）。

## 常见提问与回答

| 问题 | 回答要点 |
|---|---|
| 为什么不用 LangGraph/DB-GPT？ | 核心 Loop 与 Harness 是本项目要展示的能力；基础设施（HTTP、DB、沙箱、UI 渲染）全部复用。框架版可作为消融对照。 |
| 怎么防止模型乱写 SQL？ | 词法白名单 + DuckDB 只读连接 + 行数/超时限制，三层；没有任何写入工具。 |
| 怎么防止模型胡说数字？ | 报告数字必须来自工具结果；Trace 可逐条回指；评测检查证据字段。 |
| 沙箱安全吗？ | 默认 subprocess 只防跑飞；生产用 Docker `--network none`（镜像与配置已提供）。表述上不夸大。 |
| 效果有量化吗？ | 有 47 个单测 + 5 个验收任务；消融实验是下一步，不提前宣称提升。 |
